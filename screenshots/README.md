# screenshots - Promotional Screenshots

This directory holds screenshots of the VisClean UI, used in the README and for promotion.

## Naming Convention

- Use `NN-description.png`, for example:
  - `01-main-window.png` main window
  - `02-erase-tool.png` erase tool
  - `03-editable-pptx.png` AI editable PPTX conversion
- PNG format, recommended export width around 1600px
- Do not include personal filenames, API keys, or other sensitive information

The "Screenshots" section of the README references images in this directory.
